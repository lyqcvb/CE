# CAUEEG 复现实验分析计划（预先指定）

> 版本：2026-10-07。本文件在运行组间统计（step20）之前写定并提交；之后的任何偏离都在 `docs/results_summary.md` 中注明。预处理（step15）只读取编号列表，不读取诊断标签。

## 1. 数据与队列

- 数据：CAUEEG（`F:\数据\caueeg-dataset`，只读），200 Hz，19 通道 10-20 系统，原始导出时已平均参考。标签来自 `dementia-no-overlap.json`。
- 分组：
  - HC：Normal，排除 SMI；
  - aMCI（代码中记作 MCI）：MCI 遗忘型，排除血管性；
  - AD：Dementia 中的 AD，排除血管性痴呆与 AD/VD 混合型。
- 年龄范围 55–90 岁。
- 事件校正：EDF 不含暂停时间，而事件 JSON 的采样点索引包含暂停时间。因此 `Recording Resumed` 之后的所有事件都要减去累计暂停时长，并在暂停边界处切断片段。
- 主队列：从预处理合格者中做 1:1:1 年龄匹配。
  - 三元组内任意两组的年龄差 ≤2 岁。
  - 约束：任意两组的平均年龄差 ≤0.25 岁。
  - 目标：三元组数最多；在此前提下组内年龄差总和最小（整数规划求解）。
  - 在同一年龄内用 seed 42 随机抽取个体；另外换种子重抽 100 次，用于检验结论对抽样的稳定性。
- 敏感性队列：60–85 岁全部合格者，不匹配，模型中加入年龄与年龄²。

## 2. 预处理（step14–15）

1. **可用闭眼段**：从闭眼标记到下一个睁眼标记。以下时段从中去除：
   - 闪光刺激；
   - 过度换气（HV）期间，以及结束后 30 s；
   - 嗜睡/睡眠标记处直到下一个睁眼或闭眼标记；
   - 伪迹类标记前后各 1 s；
   - 电极检查类标记前后各 5 s；
   - 记录最后 5 s。
2. **坏导**：在 1–45 Hz 的闭眼数据上判定，满足任一条即为坏导：
   - 2 s 窗标准差的中位数 < 0.5 µV；
   - 该中位数取对数后的稳健 z 值，绝对值 > 5；
   - 先剔除前两类坏导再平均参考，然后取与最近 4 个导联的最大 |r|，其在各窗中的中位数 < 0.4。
   - 坏导超过 3 个的记录排除。
3. **参考**：平均参考，坏导不计入平均；然后做 60 Hz 陷波。
4. **ICA**：
   - 拟合用数据：除闪光、HV、睡眠以外的全部数据（睁眼和闭眼都用），经 1 Hz 高通；
   - 算法：Picard（extended，非正交）；
   - 成分数：数据秩，即 18 − 坏导数；
   - 剔除：ICLabel 判为 Muscle/Eye/Heart/Line Noise/Channel Noise 且概率 ≥0.80 的成分。
5. **分析数据**：1–45 Hz 带通 → 应用 ICA → 球面样条插值坏导 → 重新平均参考。
6. **Epoch 选取**：在闭眼段内切 2 s 不重叠 epoch，且距段边缘 ≥1 s；任一导联峰峰值 >150 µV 的 epoch 剔除；按时间顺序取前 50 个合格 epoch（共 100 s）。不足 50 个的记录排除。
7. 每人输出一份日志：坏导及判定原因、剔除的 ICA 成分及其 ICLabel 概率、合格 epoch 数、残余伪迹指标。

## 3. 指标

### 3.1 频谱（step17）

- 每个频段（δ 1–4、θ 4–8、α 8–12、β 12–30 Hz）的绝对功率与相对功率（分母为 1–45 Hz 总功率）；
- θ/α 功率比；
- 后部导联的 IAF：4–14 Hz 范围内的峰值频率和重心频率；
- specparam 非周期 offset 与 exponent。

### 3.2 连接（step18）

在连续片段上做带通滤波和 Hilbert 变换，再汇总 50 个 epoch 的样本，计算以下三种连接：

| 名称 | 定义 | 角色 |
|---|---|---|
| AEC | 包络 \|r\|，即原 LOFC 定义 | 与原稿衔接 |
| AEC-c | 逐样本正交化（Hipp 2012），两个方向取平均，负值置 0 | **主指标** |
| wPLI | 去偏平方 wPLI（Vinck 2011），负值置 0 | 稳健性 |

### 3.3 网络（step19）

- **网络类型**：
  - LOFC；
  - HOFC：原定义，两层都取绝对值；
  - sHOFC：signed HOFC，两层都保留符号；拓扑计算只用其正部，另报告带符号均值和负边比例。
- **主网络指标**：
  - 加权：MeanConn；Eglob_w、Clust_w 各自除以 50 个保持强度的零网络（Rubinov–Sporns）的均值。
  - 固定密度：在 0.20–0.40 范围内计算 Eglob/Clust 的 density-AUC，并用 Maslov–Sneppen 零网络归一化。
  - 攻击：在固定密度图上按 CE、度、介数、接近度、TOPSIS 排序移除节点，并做随机顺序对照（100 次）。结局为全局效率和最大连通分量。主终点为 AttackAUCdiff，即目标攻击 AUC 减去随机攻击 AUC。
  - 交叉验证攻击：用前 25 个 epoch 的网络排序节点，攻击后 25 个 epoch 的网络，再交换两半后取平均。
- **敏感性指标**：θ=0.35 绝对阈值下的密度、效率、聚类。

## 4. 统计（step20）

- **主终点**（8 个，AEC-c）：
  - LOFC：MeanConn、Eglob_w_norm、Clust_w_norm、AttackAUCdiff_ce_eff；
  - sHOFC：MeanConn_signed、Eglob_w_norm、Clust_w_norm、AttackAUCdiff_ce_eff。
- **主模型**：每个终点在频段内先 z 标准化，然后用线性混合模型 `value ~ group + band + age + (1|subject)`（statsmodels MixedLM，REML）检验组主效应（Wald χ², df=2）。
  - 另拟合含 group×band 交互的模型，单独检验交互项。
  - 组效应和交互效应分别在 8 个主终点内做 BH-FDR。
  - 两两比较（aMCI−HC、AD−HC、AD−aMCI）只在组效应经 FDR 校正后显著时解释。
  - 分频段的 OLS 对比（`value ~ group + age`）只在交互项经 FDR 校正后显著时解释。
- **功率校正**：在主模型中加入该频段的 log 绝对功率（z 标准化），报告 AD−HC 效应衰减的比例；另做一版以 specparam offset/exponent 为协变量。
- **稳健性分析**（不进入主 FDR 族，各自做 FDR）：
  - AEC 与 wPLI；
  - 原定义 HOFC；
  - 未归一化的加权指标、权重置换归一化、固定密度 AUC 与零模型归一化；
  - θ=0.35 阈值结果；
  - 全部排序与 LCC 结局；
  - 交叉验证攻击；
  - 加入 QC 协变量（剔除 IC 数、插值导联数、子段稳定性）；
  - 60–85 岁敏感性队列；
  - 100 次重抽样队列；
  - 逐频段 Kruskal–Wallis / Mann–Whitney（沿用 step11 的检验）。
- **CE 增量价值**：
  - 检验 group × 排序方式的交互（混合模型，5 种排序）；
  - 对每人的 AttackAUC_ce − AttackAUC_betweenness 做 TOST 等效检验，界值为 ±0.2 × 介数攻击 AUC 的受试者间 SD；
  - 报告 CE 与介数前 4 个 hub 的 Jaccard 重叠。
- **数据质量**：比较坏导数、剔除 IC 数、合格 epoch 比例、残余伪迹指标、子段稳定性在组间的差异（Kruskal–Wallis，以及控制年龄的 OLS）。
- **HOFC 收敛性**：比较 10/20/30/40/50 个 epoch 时，LOFC、HOFC、sHOFC 与全长矩阵的相关，按组和频段汇总。

## 5. 预先声明的局限

- 只有年龄可用，没有性别、教育、MMSE/MoCA。
- 诊断为临床诊断，没有生物标志物。
- 公开数据没有受试者 ID，无法排除同一受试者有多条记录。
- 1–2 Hz 的 δ 估计在 2 s epoch 下分辨率有限。
- ICLabel 在 19 导联上的可靠性低于高密度电极。
